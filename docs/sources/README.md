# Source Documents (PDS / Fact Sheets)

Place issuer documents here so metadata can be verified and traced.

## Folder layout

- `docs/sources/pds/` for Product Disclosure Statements
- `docs/sources/fact-sheets/` for monthly/quarterly fact sheets

## File naming convention

Use this format:

`<TICKER>_<ISSUER>_<DOC-TYPE>_<YYYY-MM>.pdf`

Examples:

- `MXT_Metrics_PDS_2026-05.pdf`
- `MOT_Metrics_FactSheet_2026-05.pdf`
- `PCI_Perpetual_FactSheet_2026-04.pdf`

## Notes

- Keep only the latest document per ticker unless historical versions are needed.
- If a source is a web page (not a PDF), add the URL in `docs/metadata-verification-checklist.md` notes.
