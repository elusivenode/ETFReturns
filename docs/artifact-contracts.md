# JSON Artifact Contracts (MVP)

All artifacts are generated by `scripts/run_refresh.py` and consumed by the static frontend.

## `metrics.json`
Array of ETF summary objects:

```json
[
  {
    "ticker": "VAS.AX",
    "total_return": 0.56,
    "cagr": 0.081,
    "volatility": 0.143,
    "max_drawdown": -0.291,
    "distribution_yield": 0.043
  }
]
```

## `correlation.json`
Correlation matrix payload:

```json
{
  "tickers": ["VAS.AX", "VGS.AX"],
  "matrix": [
    [1.0, 0.78],
    [0.78, 1.0]
  ]
}
```

## `rolling_returns.json`
Array with rolling return windows (1Y/3Y/5Y):

```json
[
  {
    "date": "2024-01-03",
    "ticker": "VAS.AX",
    "rolling_1y": 0.102,
    "rolling_3y": null,
    "rolling_5y": null
  }
]
```

## `portfolio_backtest.json`
Portfolio value time series:

```json
[
  {"date": "2024-01-02", "portfolio_value": 100142.21}
]
```
